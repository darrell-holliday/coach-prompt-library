# Coach Prompt Library

Prompts for online entrepreneurs and the coaches who help them. Built around one idea: use AI to get to real sales faster, not to avoid selling.

All prompts are generic. No client data, no private material.

## Prompts

- [01-buyer-research.md](prompts/01-buyer-research.md): pull your buyer's real words out of reviews and comments
- [02-offer-one-pager.md](prompts/02-offer-one-pager.md): draft a one-page offer
- [03-call-prep.md](prompts/03-call-prep.md): prep questions for a sales or discovery call
- [04-follow-up.md](prompts/04-follow-up.md): draft follow-ups you still send yourself
- [05-week-three-check-in.md](prompts/05-week-three-check-in.md): coach check-in when a client is losing steam

See a filled example in [examples/filled-offer-one-pager.md](examples/filled-offer-one-pager.md).

## Rules

- Every output gets a human edit before it goes to a buyer.
- Don't paste client names or private data into any AI tool.
